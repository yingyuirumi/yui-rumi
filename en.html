HIGH AVAILABILITY

Redundancy keeps services running.

Proxmox host-level HA protects compute; RAID and ZFS RAIDZ protect storage availability. They reduce interruption from node or disk failure, but neither one is a backup.

RECOVERY

A backup matters only if it restores.

PBS, hourly Git repository snapshots, daily VM backups, backup-of-backup and cross-region remote copies form a 3-2-1-1-0 recovery design — with verification required to reach zero errors.

DATA SOVEREIGNTY

Own the baseline. Use cloud by choice.

Open source and self-hosting sit alongside fit-for-purpose public cloud and SaaS. The difference is retaining control of data, identity, verification, migration and recovery.

SECURITY OPERATIONS

Security is a continuing operating discipline.

Identity, permissions, secrets, segmentation, asset and vulnerability management, logging, incident response and recovery drills all matter. Agents now assist patch validation, staged rollout and evidence; high-risk change still requires approval.
