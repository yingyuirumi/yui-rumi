WHY THIS EXISTS

AIで人生そのものを
自動化したいわけではない。

一人では実現できなかったものを築き、長く続けていくためにAIを使っています。

RESPONSIBILITY OVER NOVELTY

あるmodelが今日、何を新しくできるようになったか。それだけを追いかけてはいません。

Emailの要約、calendar automation、より速いcodeには確かな便利さがあります。ただ本当に知りたいのは、Agentの仕組みが長期にわたって責任を持ち、問題が起きた時に報告し、検証できるevidenceを残せるかどうかです。

A PERSONAL INVESTMENT

自分の時間、自前のインフラ、そして無理のない範囲の個人予算で。

これは会社のAIプロジェクトでも、AIで収益を上げる方法を教える企画でもありません。自分で投資し、自分で運用し、一人でできることをどこまで広げ、どこまで継続して動かせるかを試す個人的な実験です。

PERSONA AS AN OPERATING LAYER

名前、個性、関係性が、役割を日常へ連れてくる。

Personaは単なるrole-playではありません。明確なアイデンティティ、能力、境界、互いの関係が、長期的な協働を自然にし、それぞれの責任を見えやすくします。

Yingternetは、私が今も築き続ける個人のデジタル世界です。YCloudがその基盤を支え、AI Familyがそこに暮らし、働き、記憶を積み重ねていく。

HYBRID CLOUD, ON DEMAND

AWS · Google Cloud · Alibaba Cloud · Microsoft Azure — 必要な時はcloudへ。必要がなければ、自分たちのinfrastructureに残す。

HIGH AVAILABILITY

Redundancyがサービスを動かし続ける。

Proxmoxのhost-level HAがcomputeを、RAID／ZFS RAIDZがstorage availabilityを守ります。ノードやディスク障害による停止を減らしますが、どちらもbackupではありません。

RECOVERY

Backupの価値は、復元できて初めて生まれる。

PBS、hourly Git repository snapshots、daily VM backups、backup-of-backup、cross-region remote copiesで3-2-1-1-0を構成。エラーゼロを確認するための検証までがbackupです。

DATA SOVEREIGNTY

Own the baseline. Use cloud by choice.

Open sourceとself-hostingを基盤に、目的に合うpublic cloudやSaaSも活用します。違いは、データ、アイデンティティ、検証、移行、復元の主導権を手元に残すことです。

SECURITY OPERATIONS

Securityは一度の設定ではなく、継続する運用。

Identity、permissions、secrets、segmentation、asset／vulnerability management、logging、incident response、recovery drillsまで。Agentsはpatch validation、staged rollout、監査証跡を支援し、高リスクな変更には今も承認が必要です。
