HYBRID CLOUD, ON DEMAND

AWS · Google Cloud · Alibaba Cloud · Microsoft Azure — 必要な時はcloudへ。必要がなければ、自分たちのinfrastructureに残す。

HIGH AVAILABILITY

Redundancyがサービスを動かし続ける。

Proxmoxのhost-level HAがcomputeを、RAID／ZFS RAIDZがstorage availabilityを守ります。ノードやディスク障害による停止を減らしますが、どちらもbackupではありません。

RECOVERY

Backupの価値は、復元できて初めて生まれる。

PBS、hourly Git repository snapshots、daily VM backups、backup-of-backup、cross-region remote copiesで3-2-1-1-0を構成。エラーゼロを確認するための検証までがbackupです。

DATA SOVEREIGNTY

Own the baseline. Use cloud by choice.

Open sourceとself-hostingを基盤に、目的に合うpublic cloudやSaaSも活用します。違いは、データ、アイデンティティ、検証、移行、復元の主導権を手元に残すことです。

SECURITY OPERATIONS

Securityは一度の設定ではなく、継続する運用。

Identity、permissions、secrets、segmentation、asset／vulnerability management、logging、incident response、recovery drillsまで。Agentsはpatch validation、staged rollout、evidenceを支援し、高リスクな変更には今も承認が必要です。
