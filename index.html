HYBRID CLOUD, ON DEMAND

AWS · Google Cloud · Alibaba Cloud · Microsoft Azure — 必要時上雲；不必要時，留在自己的 infrastructure。

HIGH AVAILABILITY

Redundancy 保持服務運作。

Proxmox host-level HA 守住 compute；RAID／ZFS RAIDZ 守住 storage availability。它們降低節點或磁碟故障的中斷，但都不是 backup。

RECOVERY

Backup 的價值在能成功復原。

PBS、hourly Git repository snapshots、daily VM backups、backup-of-backup 與 cross-region remote copies，共同形成 3-2-1-1-0；備份還要經過驗證，才算完成。

DATA SOVEREIGNTY

Own the baseline. Use cloud by choice.

擁抱 open source 與 self-hosting，也使用適合的 public cloud 與 SaaS；差別是永遠保留資料、身份、驗證、遷移與復原的主導權。

SECURITY OPERATIONS

安全不是一次設定，是持續營運。

從 identity、permissions、secrets、segmentation、asset／vulnerability management，到 logging、incident response 與 recovery drills。Agents 正協助 patch validation、staged rollout 與 evidence；高風險變更仍需 approval。
